# spectral-history-cnn

> **n6 主实验**（当前 `project-integration` 分支）：见 [`docs/EXPERIMENT_RUNBOOK.md`](../../docs/EXPERIMENT_RUNBOOK.md) §6。  
> 入口：`CONFIG=configs/size_sweep/n6_poscnn_size64.yaml bash scripts/run_v1_pipeline_full.sh`  
> 旧 v1 配置在 `configs/legacy/`（勿用于新实验）。

Lightweight CNN pipeline for classifying the processing history of a final observed RGB image patch from its TV-residual Fourier spectrum.

The important task definition is:

- The model input corresponds to the final 64x64 image itself.
- This project does not implement `512 -> 64 -> 512`.
- For `downsample_x8`, a sample is generated by cropping `512x512` from the source image and resizing it directly to `64x64`.
- For `upsample_x2`, a sample is generated by cropping `32x32` from the source image and resizing it to `64x64`.
- The CNN sees the `64x64` final image after conversion to luminance, TV residual extraction, and real-valued log rFFT magnitude.

Class-to-crop rule in preprocessing:

- `original`, `JPEG`: crop size = `final_size`
- `downsample_xN`: crop size = `N * final_size`
- `upsample_xN`: crop size = `final_size // N` (must remain at least 4 pixels)

Classes:

| id | class |
| --- | --- |
| 0 | original |
| 1 | JPEG |
| 2 | downsample_x2 |
| 3 | downsample_x4 |
| 4 | downsample_x8 |
| 5 | downsample_x16 |
| 6 | upsample_x2 |
| 7 | upsample_x4 |
| 8 | upsample_x8 |
| 9 | upsample_x16 |

## Data Assumption

This version uses the RAISE CSV metadata file and downloads the TIFF image URL on demand.

```text
../../data/raise_raw/RAISE_1k.csv
```

The relative path above is from this project root:

```text
CNN/spectral-history-cnn/
```

The CSV must contain:

- `File`: image id, for example `r000da54ft`
- `TIFF`: direct TIFF URL, for example `http://193.205.194.113/RAISE/TIFF/r000da54ft.TIF`

Downloaded TIFF files are cached here:

```text
data/raw/raise_tiff/
```

The cache is reused, so each source image is downloaded only once.

The split is by source image, not by generated patch:

- train: 700 source images
- val: 150 source images
- test: 150 source images

Default generated sample counts:

- train: 7000 samples per class, 56000 total
- val: 1500 samples per class, 12000 total
- test: 1500 samples per class, 12000 total

Scientific caveat for v1: classes span very different source crop scales, from `upsample_x16` (`4x4 -> 64x64`) to `downsample_x16` (`1024x1024 -> 64x64`). This directly matches the intended final-observation scenario, but it may introduce scale-distribution bias. The preprocessing saves crop size and source metadata so this can be analyzed later.

## Preprocessing Details

Each final `64x64` RGB image is transformed as:

1. Convert RGB to luminance:

   ```text
   Y = 0.299 R + 0.587 G + 0.114 B
   ```

2. Normalize `Y` to float32 `[0, 1]`.
3. Compute TV residual with `skimage.restoration.denoise_tv_chambolle`:

   ```text
   residual = Y - TVdenoise(Y)
   ```

4. Compute rFFT:

   ```python
   F = torch.fft.rfft2(residual, dim=(-2, -1), norm="ortho")
   F = torch.fft.fftshift(F, dim=-2)
   ```

5. Apply DC downweighting.
6. Cache:

   ```text
   log(1 + abs(F))
   ```

The cached spectrum shape is:

```text
[1, 64, 33]
```

Only log magnitude is used in v1. No phase, real part, or imaginary part is used.

## Model

`SpectralPositionalCNN` receives:

```text
x_spectral: [B, 1, 64, 33]
```

Inside the model:

1. Normalize the spectrum per sample.
2. Concatenate fixed frequency positional channels.
3. Run a small CNN classifier.

Input channel count:

- spectrum: 1
- base coordinates: 5
- axis proximity: 2
- sinusoidal bands: 36
- total: 44

The model outputs logits:

```text
[B, 6]
```

## Notes For Later Versions

The current code is v1:

- fixed JPEG quality: QF 80
- fixed interpolation: bicubic
- TV residual only
- log rFFT magnitude only
- no DDP
- no DCT branch

Suggested extensions:

- mixed JPEG qualities
- mixed interpolation methods
- JPEG plus downsample operation classes
- DCT quantization evidence branch
- residual ablations: TV, rank residual, Laplacian
- positional encoding ablation
